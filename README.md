# 🐍 Lógica de Programação com Python

Este repositório foi criado com o objetivo de armazenar conteúdos, exercícios e exemplos desenvolvidos durante as aulas de **Lógica de Programação utilizando Python**.

## 🚀 Objetivo

Organizar e acompanhar a evolução do aprendizado em lógica de programação, aplicando os conceitos fundamentais com a linguagem Python.

## 📂 Conteúdo

Neste repositório você encontrará:

- 📌 Conceitos básicos de lógica de programação
- 🔢 Variáveis e tipos de dados
- 🔁 Estruturas de repetição (for, while)
- 🔀 Estruturas condicionais (if, elif, else)
- 📥 Entrada e saída de dados
- 🧮 Operadores matemáticos e lógicos
- 📚 Exercícios práticos
- 💡 Desafios propostos em aula

## 🛠️ Tecnologias Utilizadas

- Python
- Editor de código (VS Code e PyCharm)
- Git e GitHub

## ▶️ Como executar os arquivos

1. Instale o Python em sua máquina
2. Verifique a instalação com:
   ```bash
   python --version
3. Execute um arquivo Python com:
    python nome-do-arquivo.py
